Cấu Hình Đồng Bộ Google Sheets

Bạn có thể gửi toàn bộ kết quả đo lường (thời gian phản ứng, câu trả lời đúng/sai, chi tiết từng trial) trực tiếp lên một bảng tính Google Sheets của bạn thông qua Google Apps Script Web App.

Dán đường dẫn Deployment URL sau khi xuất bản Google Apps Script của bạn ở đây.
Chưa kết nối Webhook

Hướng Dẫn 3 Bước Cực Kỳ Đơn Giản

  1. Tạo Google Sheet mới: Vào sheets.new để tạo một Google Sheet trống.
  2. Thiết lập Apps Script: Nhấp vào Extensions (Tiện ích mở rộng) > Apps Script. Xóa hết code cũ đi và dán đoạn mã bên dưới vào: 
    
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  // Viết tiêu đề cột nếu sheet còn trống
  if (sheet.getLastRow() === 0) {
    sheet.appendRow([
      "Thời Gian", 
      "Đối Tượng (Name)", 
      "Thí Nghiệm", 
      "Tổng Số Trial", 
      "Số Câu Đúng", 
      "Tỷ Lệ Đúng (%)", 
      "Reaction Time Trung Bình (ms)", 
      "Dữ Liệu Chi Tiết (JSON)"
    ]);
  }
  
  // Ghi kết quả nhận được từ IPI TEST Studio
  sheet.appendRow([
    new Date(),
    data.participant || "Ẩn danh",
    data.projectName || "Không tên",
    data.totalTrials || 0,
    data.correctCount || 0,
    data.accuracy || 0,
    data.meanRT || 0,
    JSON.stringify(data.trials)
  ]);
  
  return ContentService.createTextOutput(
    JSON.stringify({ "status": "success" })
  ).setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  return ContentService.createTextOutput("IPI TEST Connection Test Active!");
}
  3. Triển khai Web App: Nhấp vào nút Deploy (Triển khai) > New deployment (Triển khai mới). Chọn loại là Web app. Mục Execute as chọn Me. Mục Who has access chọn Anyone (Bắt buộc để gửi dữ liệu không cần đăng nhập). Nhấp Deploy, cấp quyền và sao chép URL dán vào ô bên trái!

Chọn Mẫu Thí Nghiệm Nghiên Cứu Hành Vi

Các mẫu dưới đây được thiết kế sẵn theo đúng chuẩn các thí nghiệm tâm lý kinh điển. Khi chọn, hệ thống sẽ tự động cấu hình các slides và bảng trials tương ứng.

Nhóm 1

Tập Trung Cao (Multi-Task)

Bài test tích hợp đa nhiệm cao độ: Ghi nhớ câu hiển thị (15s), Giải phép tính nhẩm, Khoanh trắc nghiệm Tiếng Anh, và Nhiệm vụ kép (Dual-Task) kết hợp ghi nhớ đồng thời phép tính & câu từ.

🧠 Tập trung cao độ 🔢 2 trials
Nhóm 2

Phản Xạ Thói Quen (Go/No-Go)

Bài test phản xạ theo thói quen: Nhấp phím thật nhanh khi thấy Hình Tròn (Go) và tuyệt đối không phản ứng khi thấy Hình Vuông (No-Go). Lặp đi lặp lại nhiều lần để tạo thói quen phản xạ.

🎯 Phản xạ & Ức chế 🔢 10 trials
Nhóm 3

Trí Nhớ Thính Giác (Audio Memory)

Bài test nghe hiểu lời nhạc/âm thanh: Hệ thống phát ngẫu nhiên câu hát hoặc đoạn âm thanh Việt hóa, sau đó yêu cầu người chơi ghi nhớ và nhập lại chính xác lời đã nghe.

🔊 Nghe hiểu & Ghi nhớ 🔢 3 trials
Kinh Điển

Hiệu Ứng Stroop (Stroop Effect)

Đo lường sự can thiệp nhận thức khi màu chữ và nghĩa của từ xung đột nhau (ví dụ: chữ "ĐỎ" tô màu xanh lá).

⏱️ Đo Reaction Time 🔢 12 trials
Ngôn Ngữ

Quyết Định Từ Vựng (Lexical Task)

Phân loại nhanh chuỗi ký tự hiển thị trên màn hình có phải là từ có nghĩa hay không (ví dụ: "BANANA" vs "BANAAN").

⏱️ Đo nhận diện từ 🔢 8 trials
